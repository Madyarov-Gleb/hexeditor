### Инструкция по сборке и запуске проекта:

Необходимое ПО:
- JDK 8 или выше
- IDE: IntelliJ IDEA или другая
- Система сборки: Maven

Выполните команды в терминале
```
mvn clean package

java -jar target/hexeditor_java-1.0-SNAPSHOT.jar 
```

### Работа с программой

В верхнем меню расположены функции:
-	File
	-	Open - открыть файл с вашего устройства
	-	Save - сохранить измененный файл 
-	Edit
    - Copy - копировать выделенные байты
    - Cut (Zero Fill) - вырезать выделенные байты с обнулением значений
	-	Cut (Shift Left) -  вырезать выделенные файлы со сдвигом значений
	- Paste (Overwrite) - вставить значение из буфера обмена, обновив значения
	-	Paste (Insert) - вставить значение из буфера обмена со сдвигом 
	-	Insert Bytes - вставить байты, вручную указав их значение
	-	Delete Selected Bytes - удалить выделенные байты
-	View
	-	View as byte - посмотреть значение одного байта
	-	View as 2 byte - посмотреть значения двух байтов
	-	View as 4 byte - посмотреть значения четырех байтов
	-	View as 8 byte - посмотреть значения восьми байтов
-	Tools
	-	Search - поиск байт по значению, Вы можете использовать символ '?' в поисковой строке, он означает любое значение 
	-	Clear Highlight - очищает выделение после выполненного поиска

Также данные функции можно использовать, нажав правую кнопку мыши

Под строкой основного меню находятся дополнительные функции:
-	Bytes/Row - изменить число отображаемых столбцов
-	Rows - изменить число отображаемых строк
-	Offset (hex) - поиск строки по смещению 
-	Go - перейти к строке указанной в поиске
-	Next/Prev - перемещение по отображаемым страницам файла
